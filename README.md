# 🇩🇪 Deutsch Tracker – B1 Learning Journey

Welcome to **Deutsch Tracker**!
This is a clean and interactive web app designed to help you track your progress from **A1 to B1 German level in 5 months**.

The project is a **single-page HTML app** with a structured roadmap, daily tasks, and progress tracking — all stored locally in your browser.

---

## ✨ Features

### 📊 Progress Tracking

* Track your **overall progress (%)**
* Monitor **completed weeks (out of 20)**
* Visual progress arc and journey timeline

### 🗓 Structured 5-Month Plan

* 5 months roadmap:

  * Month 1 → A1 Basics
  * Month 2 → A1 → A2 Transition
  * Month 3 → A2 → B1 Start
  * Month 4 → B1 Core Grammar
  * Month 5 → B1 Consolidation
* Each month includes **weekly goals and topics**

### ✅ Daily Task System

* Predefined daily tasks:

  * 🃏 Anki Vocabulary
  * 📖 Grammar
  * 🎧 Listening
  * 🗣 Speaking/Writing
* Mark tasks as done with one click
* Daily reset + **streak tracking 🔥**

### 📈 Stats Dashboard

* Vocabulary learned
* Total study hours
* Daily completed tasks
* Days remaining in your plan

### 🧠 Notes Section

* Write notes directly in the app
* Save reflections, vocabulary, or difficulties

### 💾 Local Storage

* Your progress is saved automatically in your browser
* No account or login required

### ♻️ Reset Option

* Reset all progress anytime with one button
